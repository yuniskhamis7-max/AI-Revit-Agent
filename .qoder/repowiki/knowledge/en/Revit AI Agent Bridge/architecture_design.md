- **C# Bridge Library (`bridge-source/`)**: Implements `BridgeServer`, a lightweight `HttpListener` running on localhost (default port 8080) within the Revit process. It exposes `/tools` (discovery) and `/execute` (action) endpoints. Requests are marshalled to Revit's main thread using `ExternalEvent` and an `AgentExternalEventHandler` which invokes a registered Python delegate.
- **pyRevit Extension (`extension/`)**: A pyRevit push-button script (`script.py`) that loads the C# DLL, registers the `python_execution_router` as the execution delegate, and toggles the server state. It contains a dynamic tool registry and implementations for various Revit actions (e.g., `create_grid`, `place_family`).
- **Interaction**: The C# layer handles network I/O and thread safety, while the Python layer handles Revit API logic and tool dispatching, leveraging IronPython's integration with the .NET CLR.
